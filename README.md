# 🌾 Farm Layout & Item Modifier – Harvest Moon: Back to Nature by Maru

Aplikasi bantu untuk **Harvest Moon: Back to Nature (PS1, NTSC-U)**. Anda bisa mendesain tata letak kebun dan mengisi inventori secara visual, lalu aplikasi membuatkan kode GameShark yang tinggal ditempel ke emulator.

> Dibuat oleh **Maru**. Proyek penggemar, tidak berafiliasi dengan Natsume atau Marvelous.

## Fitur

**Tab Kebun**
- Grid 45 × 25 (1125 petak) di atas gambar peta kebun.
- Palet bibit, rintangan, dan status tanah (cangkul, siram, normal) yang bisa digulir.
- Alat gambar: kuas, kotak, pilih range, isi range, dan klik kanan untuk menghapus.
- Range desain: hanya area yang dipilih yang dibuatkan kode.
- Highlight petak dan info nomor petak saat kursor lewat atau saat disentuh.

**Tab Item Modifier**
- Ubah isi Rucksack, Equipped, dan Toolbox 1–8 beserta jumlahnya (1–99).
- Daftar sekitar 320 item dengan pencarian nama atau kode.
- Menu Lainnya: uang, medali, lumber, fodder, fish food, dan chicken feed.

**Umum**
- Copy Codes dan Create File (file teks siap tempel ke emulator).
- Save, Load, dan Hapus layout.
- Tampilan terang dan gelap otomatis, muat dalam satu layar.

## Cara pakai
1. Di tab **Kebun**, pilih item lalu gambar di grid.
2. Di tab **Item Modifier**, pilih penyimpanan, pilih item, lalu isi jumlah.
3. Klik **Copy Codes** atau **Create File**, lalu tempel ke menu cheat emulator.
4. Coba dengan sedikit petak atau slot dulu sebelum memakai desain penuh.

## Build EXE dan APK
Proyek siap build ada di `Farm-Layout-Item-Modifier-build-project.zip`.
1. Upload isinya ke repository GitHub.
2. Buka tab **Actions** dan jalankan **Build EXE dan APK**.
3. Unduh `.exe` dan `.apk` dari bagian **Artifacts**.

## Catatan
- **Cadangkan save atau save state** sebelum memakai kode.
- Hanya untuk versi **NTSC-U**.
- Gambar item di palet memakai emoji dan gambar sederhana, bukan sprite asli game.
- APK yang dihasilkan berupa versi debug untuk pemakaian pribadi.
