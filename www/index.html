Lanjutan

Item ditulis ke field +0, status tanah ke field +2, tipe tanaman ke field +4; jarak antar petak 8 byte. Cangkul = 0168, Siram = 0169, Normal = 0167. Bibit bisa panen ulang (Cucumber, Strawberry, Tomato, Corn, Pineapple, Eggplant, Sweet Potato, Green Pepper) = 0003, bibit lain = 0002, Rumput = 0036 / 0167 / 0302. Bibit tanpa status tanah otomatis disiram (0169). Belum disiram = 0168 (petak terang). Nilai field +4 menurut pertumbuhan: panen sekali = 0001 (dalam pertumbuhan) / 0002 (siap panen); panen ulang = 0002 (dalam pertumbuhan) / 0003 (siap panen).
